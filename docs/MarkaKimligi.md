# OhHike - Marka Kimliği (v4.0 — MVP)

## 1. Temel Marka Bilgileri
* **Uygulama Adı:** OhHike
* **Hikaye / Çıkış Noktası:** Spor takımlarının dağınık antrenman verilerini, sporcu check-inlerini ve performans notlarını tek bir panelde toplama fikri.
* **Slogan:** "Takımını tek yerden yönet."
* **Maskot:** Doktor Panda. Antrenörü ve sporcuyu yargılamayan; check-in, yük ve recovery verilerini sade şekilde sunan profesyonel koç asistanı.

## 2. Domain ve Altyapı
* **Tanıtım (Landing Page):** ohhike.com (Statik tanıtım sayfası)
* **Ana Uygulama (Web App):** app.ohhike.com (Login, dashboard, takım yönetimi)
* **Mimari:** Monorepo (Next.js frontend + Express.js backend)
* **Veritabanı:** MongoDB
* **Auth:** Clerk
* **İş Modeli:** Şu an ücretsiz MVP. Ödeme sistemi ileride eklenecek (Coming Soon).

## 3. GitHub Yapılandırması
* **Repo Adı:** ohhike
* **Repo Açıklaması:** A coaching operations platform for sports teams. Manage teams, athletes, sessions, and daily check-ins from one dashboard.
* **Etiketler:** `nextjs`, `expressjs`, `mongodb`, `monorepo`, `sports-tech`, `coach-dashboard`

## 4. Tasarım Sistemi Önizlemesi
* **Temel Felsefe:** Samimi, modern, yuvarlatılmış (rounded) hatlar ve göz yormayan bir arayüz.
* **Ana Renk (Primary):** Soft Turkuaz
* **Destekleyici Renkler:** Doktor Panda'nın bildirimlerinde kullanılacak soft pastel tonlar.
* **Tipografi:** Okunabilirliği yüksek, köşeleri yumuşak sans-serif fontlar (Örn: Nunito, Quicksand).
